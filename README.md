# Scaley-A-Greyscale-Application
A java application that converts a photo to two grayscaled (/3 and weighted average) photos, of any file type. It will save it to the root of your folder.


HOWTO: Using Scaley.
-When running the program, you will be prompted to add a photo.
-Upon adding the photo, the method goes pixel by pixel (single threaded, linear, will redo later), converting each to B&W. This might take a while with large photos but otherwise working perfectly.
-The image will be saved to the root folder of the project.
